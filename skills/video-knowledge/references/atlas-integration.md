# EGA Atlas — persistence rules

Load this reference only for requested persistence or Atlas audits, then verify **live** `egawilldoit/ega-atlas` rules: `AGENTS.md`, `now.md`, `index.md`, relevant `wiki/` pages and `.agents/skills/atlas-{query,update,ingest,lint}/SKILL.md`. The repo is public; these rules may change.

- **One topic = one canonical page.** Search before creating. Existing `wiki/concepts/time-management.md` is the canonical home for Video 01; do not create `time-management-video-02.md`. No unapproved new top-level or wiki folders.
- Prefer existing `wiki/concepts/` for techniques, `wiki/areas/` for ongoing habits, `wiki/projects/` only for bounded deliverables; preserve current template structure and frontmatter (`type`, `status`, `updated`, `related`).
- Original transcripts and articles are sources; do **not** automatically commit them to public `raw/`. Do not publish confidential data, private chats, tokens, personal records, employer content or copyrighted full transcripts without rights. When in doubt, only link the external video and write an independently worded summary.
- Wiki notes contain compact reusable insights, original source links, practical exceptions, a Mermaid visual, and relative links working in Obsidian and GitHub. Do not fabricate `raw/<path>` citations for uncommitted sources.
- Compare any new video's lessons against related pages. Keep both sides of a real contradiction with attributed sources rather than silently overwriting.
- Update `index.md` if a new page or summary needs indexing; `now.md` **only** for changed priorities; `log.md` after authorized mutations. Read related pages and use repo-local lint.
- Fetch/pull current state, preserve concurrent edits, follow allowed branch/PR/merge scope, never force-push. Read back remote content before claiming publication.

The user's request to **analyze a video** alone does not authorize a GitHub change.
